当前可以投递主项目。面试重点是已经实际完成的 GPIO、I2C、字符设备、生命周期和 V4L2 采集；BSP 衍生在完成后追加，不提前宣称“完整 BSP 移植”。

## 本次 BSP 衍生的任务列表

1. 核对源码、配置、工具链、启动布局、恢复条件——配置/启动分析、Windows boot 备份校验、MASKROM 识别及退出后旧系统启动通过；定点恢复未验证。
2. 可重复构建厂家 ARM64 内核、模块、DTB——已完成云端构建与离线产物校验。
3. 自编 MPU6050 接入 Kconfig/Kbuild，启用为 m——已通过完整源码树构建。
4. 核对 I2C7/MPU6050 设备树与 overlay——两个 overlay 在新基础 DTB 上离线合并通过，实际启动待验收。
5. 保留回退入口，启动本次构建内核——LOADER/GPT/完整 boot 读回已核对，配套离线包和分步安装/切换/回退脚本已完成；待实板 stage 与启动，新内核和分区恢复均未实测。
6. 摄像头、按键、MPU6050 最小回归——待新内核启动后执行。
7. 一次可恢复的设备匹配排障实验——待执行。
8. 归档构建、部署、验收和面试材料——持续更新。
